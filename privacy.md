Privacy Policy – Personal Finance Sync

Last updated: 10 October 2026

1. Purpose

Personal Finance Sync is a non-commercial application developed exclusively for personal financial management.

2. Data collected

The application may access account balances, transaction dates, transaction amounts, currencies, transaction descriptions, and account identifiers through Enable Banking, with the account holder's authorization.

3. Data usage

Financial data is used exclusively to create and update private personal finance spreadsheets. The application does not sell financial data or use it for advertising.

4. Data storage

Transaction data is intended to be stored in a private Microsoft OneDrive account. Technical credentials used for automated synchronization are intended to be stored securely.

5. Data sharing

Banking data is processed through the authorized banking connectivity provider Enable Banking. The application does not intentionally publish financial transactions or share them with unrelated third parties.

6. Data retention and deletion

Financial records are retained for personal bookkeeping purposes and can be deleted by the account holder. Access authorizations may be revoked through the relevant banking provider.

7. Contact

For privacy-related inquiries, contact the application owner using the email address provided during application registration.
